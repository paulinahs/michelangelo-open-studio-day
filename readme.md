# Michelangelo's Open Studio Day

A responsive event landing page built with HTML and CSS. The page presents a fictional open studio day where visitors can explore Michelangelo's work through exhibitions, demonstrations, and guided tours.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid


## Takeaways

Learned that ⌘ + command + m gives you the problem panel that indicates the error that is highlighted.

## Questions from teacher ##

## 1. Vad innebär semantisk HTML och varför har ni använt det på er eventsida?

Semantisk HTML innebär att man använder taggar som beskriver innehållets betydelse, till exempel `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` och `<footer>`. Vi har använt semantisk HTML för att göra sidan mer lättläst, strukturerad och tillgänglig för både användare och sökmotorer.

---

## 2. Hur fungerar arv i CSS? Ge ett exempel från er egen kod.

Arv i CSS innebär att vissa egenskaper automatiskt förs vidare från ett föräldraelement till dess barn. Exempelvis kan textfärg och teckensnitt ärvas. I vår kod använder vi `text-align: center` på vissa sektioner, vilket gör att texten i de underliggande elementen också centreras om den inte får en egen regel.

---

## 3. Vad är den största skillnaden mellan Flexbox och CSS Grid, och när ska man använda vilket verktyg?

Flexbox används för att arrangera innehåll i en riktning, antingen som en rad eller en kolumn. Vi använde Flexbox i highlights-sektionen för att placera aktivitetskorten bredvid varandra på ett flexibelt sätt.

CSS Grid används för tvådimensionella layouter med både rader och kolumner. Vi använde Grid i schemat eftersom det behövde organiseras i tydliga kolumner för tid, aktivitet och plats.
